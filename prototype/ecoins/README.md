# E-coins – prototype og økonomimodell (fase 1–3)

Ikke en del av nettsiden. Ingenting her er godkjent eller publisert.

- `E-COINS-PLAN.md` – beslutningsgrunnlaget
- `modell.py` → `modell-ut.json` – milepæler, priser og simulering (`python3 modell.py`)
- `app.html` + `bygg.py` – kilde til den interaktive prototypen. `bygg.py` bygger inn three.js r128, GLTFLoader (fra Dyrepatruljen), roboten (`felles/robot/helt-robot.glb`) og fontene til én fil. Stiene i skriptet må tilpasses

Sikkerhet

EVN Studio er spillstudioet til Even, 9 år. Det er et lite, ikke-kommersielt nettsted med gratis spill i nettleseren. Denne siden er skrevet for foreldre, skoler og IT-avdelinger som vil vurdere nettstedet.

Sist oppdatert 31.10.2026

Kort fortalt

  • Ingen innlogging, kontoer, reklame, kjøp, chat eller innhold fra andre brukere.
  • Ingen informasjonskapsler (cookies) og ingen innsamling av navn, e-post eller andre opplysninger om hvem du er. Anonym bruksstatistikk er beskrevet på personvernsiden.
  • Alle sider er statiske filer. Det finnes ingen server som tar imot data fra besøkende.
  • Kildekoden er offentlig: github.com/ivarbrov/evnstudio.

Drift og kryptering

  • Nettstedet driftes på GitHub Pages. Domenet evnstudio.no er registrert hos Domeneshop.
  • All trafikk går over HTTPS. Besøk på http sendes videre til https.
  • TLS-sertifikatet utstedes av Let's Encrypt. CAA-posten tillater bare Let's Encrypt.
  • DNSSEC er slått på, og domenet er verifisert i GitHub.
  • GitHub-kontoen er beskyttet med tofaktorautentisering. Hovedgrenen kan ikke slettes eller overskrives.

Sikkerhetstiltak i nettleseren

  • Alle sider har en innholdspolicy (Content Security Policy). Den tillater bare skript fra evnstudio.no og statistikkskriptet, og bare nettverkstrafikk til evnstudio.no og GoatCounter.
  • Spillene bruker ikke iframes, skjemaer, eval eller innhold som andre har lagt inn.
  • Spillfremgang lagres bare lokalt i nettleseren (localStorage) og sendes aldri noe sted.

Begrensninger

GitHub Pages lar oss ikke sette egne HTTP-headere. Innholdspolicyen er derfor satt i sidenes HTML. HSTS med preload, Permissions-Policy og beskyttelse mot innramming (frame-ancestors) er ikke satt.

Blokkert på jobb eller skole?

Domenet ble registrert i oktober 2026. Mange sikkerhetsfiltre blokkerer domener som er nyere enn 30 dager, eller som ikke har fått en kategori ennå. Nettstedet inneholder spill, så noen virksomheter blokkerer det også med vilje. Kontakt i så fall din egen IT-avdeling. De kan be leverandøren av sikkerhetsfilteret om å kategorisere domenet.

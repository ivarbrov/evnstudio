EVN Testsuite

Automatiske, objektive tester for alle spill (krav merket A i EVN Game Standard). Virker bare lokalt (localhost eller 127.0.0.1). Ingenting sendes til GoatCounter.

Kjøres av node test/kjor.mjs i Chrome eller Edge uten skjerm. Skriptet finner spillene i spill/ og gir listen til denne siden, så siden virker bare via skriptets egen server. Velg enkelte suiter med --suiter statisk,royk.

Grunnlag: agent 2.2 (utkast), standard 1.2 (utkast, ikke godkjent; gjeldende er 1.1) (119ac87f3b1a36769c7e1339cc640fe3c895880f), commit d0612d039bccf759acb4afe8a4c756f8244d1c6f

Nivå: full – versjonen skal foreslås publisert. Selve endringen er middels (HUD, Tab-håndtering og dialogtekst i ett spill, uten endring i spill.js, lagring eller statistikk).
Testet: Linux-container med 2 CPU-er og uten GPU, frakoblet arbeidstre på d0612d0 (rent før og etter).
- `node test/kjor.mjs --base origin/main` i headless Google Chrome: 73 ok, 0 feil, 0 varsel, 0 kjent, 2 ikke innført (statistikk, ui).
- **Egne tester:** Python Playwright med Google Chrome headless (SwiftShader) mot `python -m http.server` på 127.0.0.1:8931. Hver kjøring fikk en ny, tom nettleserprofil, og `localStorage` ble tømt før og etter. Grafikk ble satt til «Lav» (`mork3d.q`), ellers var maskinen for treg.
- **Metode:**
  - Ekte museklikk på elementets koordinater.
  - Ekte tastetrykk: Tab, P, H, I, Esc og Enter.
  - `spill.js` ble levert fra minnet med testkroken `window.__qa` lagt til på slutten, for å lese `state` og `hero` og for å kalle `gameOver()`. Repoet er ikke endret.
- **Størrelser:** 1280×800 (PC), og 375×812, 740×360, 320×568 og 568×320 med emulert berøring (`touchui` aktiv). I mobilstørrelsene ble det brukt museklikk, ikke ekte berøring.
- **Avbrudd:** Testmiljøet startet på nytt to ganger underveis. Berørte kjøringer er tatt om i mindre deler. Ingen resultater er hentet fra andre commits.
- **Testserver:** Port 8931 er stoppet, og ingen Chrome-prosesser kjører.

Merk om grunnlaget: Oppdraget sier ikke hvilken standardversjon som gjelder. I repoet ligger 1.2 (utkast). Jeg har kontrollert mot de gjeldende kravene (1.1, med S2 slik den er presisert i 1.2a). UI1–UI10 er ikke tatt i bruk i Mørkeskogen, og klarspråk har status forslag. Ingen av dem er kontrollert.

**Flettingen:**
- `git diff origin/main HEAD` gir `hud2.css`, `hud2.js` og `index.html` i spillet, `ENDRINGSLOGG.md` og fem tidligere QA-rapporter.
- `spill.js`, `grafikk2.js` og `statistikk.js` er byte-like med main, og origin/main er forfar til HEAD.
- Spillfilene er like med PR #26 (1b020b1/44a6e67), utenom versjonslinja, endringene fra 2.0.2 og stien til `helt-robot-v2.glb`.
- `index.html` er lik PR #31 (7d6ec26), utenom endringene fra 2.0.1 og versjonslinja.

## Anbefalte forbedringer
- **«🚪 Avslutt» på game over i liggende format:** I 740×360 og 568×320 er kortet 431 px høyt.
  - «🚪 Avslutt» ligger på y 345–389 og y 344–388, altså under skjermkanten. Spilleren må rulle for å se knappen.
  - «Prøv igjen» er synlig.
  - Forslag: kompakt kort når skjermen er lav, eller knappene side om side.
- **Fokus etter «Nei» fra game over:** Send fokus tilbake til «🚪 Avslutt» eller «Prøv igjen», på samme måte som `EVNNullstill` gjør med `forrige`.
- **Tab-lytteren i `hud2.js`:** Flytt bare fokus til toppraden når ingen dialog er åpen (`#menu`, `#evnPause`, `#evnSporsmal`, `#overScreen`). Uendret forslag fra 1b020b1.
- **Toppraden på game over:** ❓ og ✕ i toppraden er fortsatt synlige over game over-kortet, i tillegg til «🚪 Avslutt» i kortet. Det er ikke testet hva ❓ gjør over game over. Vurder å skjule toppraden der.

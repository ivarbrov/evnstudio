# EVN Game QA: Mørkeskogen 2.0.3, Dyrepatruljen 0.11.5 og E-shop (EVN-roboten v2, ny kontroll etter fletting med main)
Grunnlag: agent 2.2, standard 1.2 (utkast; gjeldende 1.1) (119ac87f3b1a36769c7e1339cc640fe3c895880f), commit 9692ac2a32deb4a1065d7f3de5e236de120d189b
Testkvittering: evn1 commit=9692ac2a32deb4a1065d7f3de5e236de120d189b tester=38fef252df52 arbeidstre=rent statisk=ok royk=ok statistikk=ikke-innfort ui=ikke-innfort ecoins=ok
Nivå: full – versjonen skal foreslås publisert. Endringen gjelder en felles ressurs (samme GLB i to spill og i E-shop/garderoben), og flettingen hadde en konflikt i ENDRINGSLOGG.md og en automatisk fletting i `butikk/butikk.js`.
Testet: Windows 11, arbeidsmappa på 9692ac2 med rent arbeidstre (før og etter). `node test/kjor.mjs --base origin/main` i headless Chrome ga 73 ok, 0 feil, 0 varsel, 0 kjent og 2 ikke innført. Repoet ble servert med `python -m http.server` på 127.0.0.1:8953 og testet i nettleserpanelet (Chromium). Panelet var skjult, så noen klikk måtte tas om. Metoden var ekte museklikk på ref eller koordinat, og Esc, P, Enter og W ble gitt som ekte tastetrykk. `javascript_tool` ble bare brukt til å sette opp lagring og til å måle. Størrelsene var panelets egen (cirka 800×450) og emulert 375×812 og 740×360, med iframe i riktig størrelse. GLB-filene og base64-strengen ble kontrollert statisk med Node (SHA-256). `localStorage` ble tømt før og etter testene.

Merk om grunnlaget: Oppdraget sier ikke hvilken standardversjon som gjelder. I repoet ligger 1.2 (utkast), og gjeldende godkjente versjon er 1.1. Jeg har kontrollert mot de gjeldende kravene. UI1–UI10 er ikke tatt i bruk i noen av spillene, og klarspråk har status forslag. Ingen av dem er kontrollert.

## Anbefalte forbedringer
- Fiskespillet bruker fortsatt v1-roboten. I garderoben vises v2, så barnet ser to ulike roboter. Endringsloggen nevner dette som en egen endring, så det er kjent og ikke en feil. Det bør likevel tas med i neste runde.
- `grafikk2.js` og spillsidene har ingen versjonsparameter i URL-en, så nettleserbufferen kan vise gammel kode en tid. Det er ufarlig så lenge `modeller/helt-robot.glb` beholdes, og den bør beholdes.
- Dyrepatruljen har ingen LISENSER.md. Opphav og lisens står bare i kodekommentaren. Det fantes før og er ikke et krav.
